A python script to search huggingface datasets for mentions of seeking support around major social transitions.

A bash script to set environment variables and determine the arguments. 

You must be granted access to lmsys/lmsys-chat-1m and apply for permission to access allenai/WildChat-4.8M-Full

The python script includes functions to use an LLM to evaluate the conversations. However we were not able to achieve good accuracy for this.
